# Documentation EJBCA Oculox

La procedure de reference est [Installation trois VM](installation_3_vm_et_bundles.md).
Elle couvre le bootstrap, les agents mTLS, Core, Cluster, Collecteur et
l'exploitation. Les commandes correspondent aux scripts du depot.

[Livraison et preuves de test](livraison_ejbca_2026-09-30.md) distingue les
fonctionnalites implementees, les essais effectues et la recette sur VM neuves.

Les documents `phases_*`, `preparation_trois_vm.md` et l'audit du 29 septembre
sont des rapports historiques. Le [plan de developpement](plan_developpement_integration_ejbca.md)
conserve les objectifs et les decisions; il ne remplace pas la procedure actuelle.
